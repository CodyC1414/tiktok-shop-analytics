Privacy Policy

TikTok Shop Analytics is a private analytics tool that connects to TikTok via OAuth.

The application only accesses data explicitly authorized by the user through TikTok’s consent screen. This data is used solely for analytics and reporting purposes for the authenticated account.

No personal data is sold or shared with third parties. Data is stored locally and used only to generate insights for the user.
